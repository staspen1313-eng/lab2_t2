# Алхімічна лавка

Навчальна гра на Vue 3 та TypeScript: купуйте інгредієнти, відкривайте рецепти, варіть зілля та виконуйте замовлення покупців.

## Запуск

Потрібен Node.js 22.18 або новіший.

```bash
npm install
npm run dev
```

Команда запускає Vite та API-сервер. Інтерфейс доступний за адресою `http://localhost:5173`.

## Перевірки

```bash
npm test
npm run build
```

## Структура

- `src/` — Vue-інтерфейс, ігровий стан, API-клієнт і збереження прогресу.
- `backend/` — Express API, розділене на маршрути, контролери, сервіси та репозиторій.
- `shared/` — спільні контракти TypeScript для клієнта й сервера.

Налаштування Vite зберігаються у `.env.development`: `VITE_API_URL` задає адресу API для клієнта, а `API_PROXY_TARGET` — ціль проксі `/api`.
